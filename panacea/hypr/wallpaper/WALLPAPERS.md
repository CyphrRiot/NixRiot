# NixRiot Wallpapers

The set is 29 WebP images, `00.webp` through `28.webp`, generated for NixRiot.
They are the project's own work and carry no third-party terms.

This set replaced the earlier OpenRiot background collection, which was
BSD-3-Clause and borrowed. That collection is no longer shipped.

| File | Source | License |
|---|---|---|
| `00.webp` through `26.webp` | Generated for NixRiot | NixRiot project, no third-party license |
| `27.webp` | User-provided (`~/Downloads/25.jpg`) | NixRiot project, license to confirm |
| `28.webp` | User-provided (`~/Downloads/28.jpg`) | NixRiot project, license to confirm |

The default is `27.webp`, referenced by `hypr/wallpaper.conf` and
`hypr/hyprpaper.conf`.

To add an image, place it here and add a row above with its author, source,
and license. Do not add an image without a license entry.

Live video wallpapers belong in `live/` and are optional. They are not
shipped in the base image.
