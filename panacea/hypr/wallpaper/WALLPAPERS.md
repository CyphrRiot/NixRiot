# NixRiot Wallpapers

The set is 33 WebP images, `00.webp` through `32.webp`. The first 27 were
generated for NixRiot; the later additions are user-provided.

This set replaced the earlier OpenRiot background collection, which was
BSD-3-Clause and borrowed. That collection is no longer shipped.

| File | Source | License |
|---|---|---|
| `00.webp` through `26.webp` | Generated for NixRiot | NixRiot project, no third-party license |
| `27.webp` | User-provided (`~/Downloads/27.jpg`, dark) | NixRiot project, license to confirm |
| `28.webp` | User-provided (`~/Downloads/28.jpg`) | NixRiot project, license to confirm |
| `29.webp` | User-provided (`~/Downloads/grok-image-22bfd5b6`) | NixRiot project, license to confirm |
| `30.webp` | User-provided (`~/Downloads/grok-image-6344b729`) | NixRiot project, license to confirm |
| `31.webp` | User-provided (`~/Downloads/grok-image-84614c04`) | NixRiot project, license to confirm |
| `32.webp` | User-provided (`~/Downloads/grok-image-fe15e1d4`) | NixRiot project, license to confirm |

The default is `22.webp`, referenced by `hypr/wallpaper.conf` and
`hypr/hyprpaper.conf`.

To add an image, place it here and add a row above with its author, source,
and license. Do not add an image without a license entry.

Live video wallpapers belong in `live/` and are optional. They are not
shipped in the base image.
